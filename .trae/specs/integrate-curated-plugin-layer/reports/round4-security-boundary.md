# Round 4 Security Boundary Audit

## Status

No demonstrably exploitable security issue survives this review. The remaining items are defense-in-depth suggestions because exploitation requires control of trusted local CLI/configuration input, the checked-in curated catalog, or an installed plugin that already executes with the DSH process's authority.

This is a fresh Task 17 audit: the task requires current source evidence rather than prior progress conclusions (`.trae/specs/integrate-curated-plugin-layer/tasks.md:[L101,L105]`), while the specification requires pinned candidate metadata, bounded smoke execution, secret rejection, and immutable rollback evidence (`.trae/specs/integrate-curated-plugin-layer/spec.md:[L55,L67]`, `.trae/specs/integrate-curated-plugin-layer/spec.md:[L125,L151]`).

None.

## Hardening Suggestions

1. Resolve artifact files with platform-aware absolute-path rejection and canonical `realpath` containment. The current lexical check rejects `/`, NUL, and `..`, but does not explicitly reject Windows drive/UNC paths or symlink escapes (`packages/curated/curated-scripts/src/index.ts:[L729,L736]`). This is not a demonstrated exploit in the current curated set because the values come from checked-in or locally installed metadata.
2. Resolve `pnpm.cmd` directly on Windows and keep `shell: false`. The current Windows-only shell mode forwards local CLI arguments (`apps/cli/src/plugin.ts:[L130,L136]`); removing the shell would reduce future risk if an untrusted caller is ever added.
3. Reject `!!js` nodes specifically in preflight fields that represent security policy, or document that those checks are static assertions only. Preflight recursively checks concrete values such as `captureBody`, `importMode`, session writes, and body egress (`packages/curated/curated-scripts/src/index.ts:[L2544,L2588]`), while runtime patch parsing intentionally preserves expression nodes (`packages/boot/app-boot/src/index.ts:[L202,L207]`).
4. Bind each embedded rollback snapshot's `profile` and the benchmark's `lockSnapshot`/`profileSnapshot` references to the compared profiles. Current validation proves digest and payload structure (`packages/curated/curated-scripts/src/index.ts:[L1483,L1524]`) but does not provide signer authenticity or enforce that every reference names the embedded envelope. This matters only if benchmark JSON later crosses an authenticated publication boundary.

## Disposition

The security result is clean for the current trust model. The four hardening items do not meet the exploitability threshold and should not block Task 17; they should be reconsidered if curated admission begins processing remotely supplied profiles, artifacts, or benchmark attestations.
