# Fusion TUI profile 交付状态

[English](fusion-tui-profile.md) | 中文

Fusion TUI 公开交付处于 **BLOCKED** 状态。DeepSeek Harness 不提供创建、添加、验证或启动该 profile 的受支持命令。

## 这意味着什么

通过源码验证的 TUI 运行时不等于受支持的公开安装。不要把注册表包安装到混合 Harness 依赖图中，也不要把源码验证配置复制到用户 profile。

当前受支持的 Fusion 界面是[仅含 Pet 的 Fusion Web profile](fusion-profile.md)。拥有该决策的 [Fusion 外部插件决策](../../../.agents/notes/implemented/architecture/2026-08-19-fusion-profile-external-plugin-ownership.md)记录当前 TUI 阻塞原因、证据限制和重新准入要求。
