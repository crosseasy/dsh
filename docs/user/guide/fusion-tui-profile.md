# Fusion TUI profile delivery status

English | [中文](fusion-tui-profile.zh.md)

Fusion TUI public delivery is **BLOCKED**. DeepSeek Harness does not provide a supported command to create, add, verify, or start this profile.

## What this means

A source-validated TUI runtime is not a supported public installation. Do not install the registry package against a mixed Harness dependency graph or copy the source-validation setup into a user profile.

Use the [Pet-only Fusion Web profile](fusion-profile.md) for the currently supported Fusion interface. The owning [Fusion external-plugin decision](../../../.agents/notes/implemented/architecture/2026-08-19-fusion-profile-external-plugin-ownership.md) records the current TUI blocker, evidence limits, and re-entry requirements.
