# superpowers 文档辩证优化实施计划

**Goal:** 保留 `00`–`05` 的事实基线，由 [06](../06-深度调研复评与证据分级.md) 集中持有深度调研的证据分级、候选复评和方法论限制，并让各 owner 文档引用同一组当前事实。

**Architecture:** `06` 是 E0–E5、`evidenceKind` 非映射关系和候选复评的唯一详细说明；README 只负责导航，`00`–`05` 只保留各自主题所需的本地约束和到 `06` 的链接。

**Tech Stack:** 中文 Markdown、仓库相对链接、叶级文档门禁。

## Global Constraints

- `web-curated` 保持目标 12、静态/安装资格候选 6、runtime active 0；候选初始化、生命周期与用户路径 E3/E4 证据均为 pending，完整启用条件由 [06](../06-深度调研复评与证据分级.md) 持有。
- 新蓝本统一引用为“深度调研补充〔2026-08-25 §X〕”，不得混同原蓝本的 `§1`–`§9`。
- 独立 artifact root 只能得到 metadata-only、`observed:false` 结果；package-authored `.dsh-curated-artifact.json` 不能建立 observed success。
- 本轮不执行 `git add`，且不改变任务开始前既有 index。其他 Git 写操作需用户显式授权。
- 文档保持中文、每段一行；每条验证命令用 `gtimeout 50s` 限时。
